# Plataforma Red Soluciones

## Objetivo

Plataforma logística para:

- Cotizaciones nacionales
- Cotizaciones internacionales
- Domicilios locales
- Generación de guías
- Rastreo
- Administración de clientes
- Administración de transportadoras
- Pagos
- Billetera
- Facturación

---

## Tecnologías

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

- Landing
- Cotizador
